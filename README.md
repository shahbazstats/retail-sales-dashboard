
# 📊 Retail Sales Dashboard

## Project Overview

This Retail Sales Dashboard was developed using Microsoft Power BI to analyze retail business performance and provide actionable insights for sales and profitability.

## Tools Used

- Power BI
- Power Query
- DAX

## Dashboard Features

- Sales Performance Analysis
- Profit Analysis
- Product Category Analysis
- Customer Insights
- Regional Sales Analysis
- KPI Dashboard
- Interactive Filters and Visualizations

## Skills Demonstrated

- Data Cleaning
- Data Modeling
- DAX Measures
- KPI Development
- Interactive Dashboard Design
- Business Insight Generation
- Data Visualization
